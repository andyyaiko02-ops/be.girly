BE.GIRLY — TIENDA DE ROPA

Proyecto creado con HTML, CSS y JavaScript sin frameworks.
Las imágenes de logo, banners y prendas se han extraído del PDF proporcionado para mantener la identidad visual del prototipo.

ARCHIVOS
- index.html: estructura de la tienda.
- styles.css: estilos rosa y blanco, diseño responsive.
- script.js: búsqueda, carrito y modal de confirmación.
- assets/: imágenes originales y recortes extraídos del PDF.

CÓMO ABRIR
1. Descomprime el proyecto.
2. Abre esta carpeta en Visual Studio Code.
3. Abre index.html en un navegador, o usa la extensión Live Server.

FUNCIONALIDAD
- Busca por nombre de prenda.
- Añade prendas y ofertas al carrito.
- Actualiza el contador, las cantidades y el total.
- Muestra el modal “¡Solicitud registrada con éxito!”.

NOTA
El carrito es una simulación local en memoria. No guarda pedidos en servidor ni procesa pagos reales. Algunas funciones visuales se basan en el diseño del PDF, y los botones de ubicación/perfil muestran avisos de demostración porque el PDF no especifica esos flujos.
